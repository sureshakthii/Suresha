# கைப்பேசி ஜோதிடர் — உங்கள் கைப்பேசியில் நிறுவும் எளிய வழிகாட்டி

வணக்கம்! 🙏 இந்த வழிகாட்டி உரிமையாளராகிய உங்களுக்காக எழுதப்பட்டது. கணினி நிரலாக்கம் (programming) தெரிய
வேண்டியதில்லை. ஒவ்வொரு படியையும் வரிசையாகச் செய்தால் போதும்.

**முக்கியச் செய்தி:** இப்போது சேவையகம் (server) இல்லாமலேயே செயலியைச் சோதிக்கலாம். சேவையகம் இல்லாதபோது
உருவாகும் செயலி "தனித்து இயங்கும் செயலி" (standalone app). ஜாதகம், பொருத்தம், பஞ்சாங்கம், பிரசன்னம்
போன்ற எல்லாக் கணக்குகளும் கைப்பேசியிலேயே நடக்கும். இணையம் இல்லாவிட்டாலும் இயங்கும்.
உள்நுழைவு (login), கட்டணம், முன்பதிவு, வானிலை ஆகியவை மட்டும் சேவையகம் வந்த பிறகே இயங்கும். அவற்றின்
இடத்தில் "சேவையகம் தேவை" என்ற அட்டை தெரியும். இது சரியானதுதான், பயப்பட வேண்டாம்.

## அ) இன்றே சோதிக்க மிக எளிய வழி: முகப்புத் திரையில் சேர்த்தல்

செயலியின் இணைய இணைப்பு (web link) உங்களிடம் இருந்தால், கடையில்லாமலே கைப்பேசியில் செயலி போல நிறுவலாம்.

**ஆண்ட்ராய்டு (Android) — Chrome உலாவி:**

1. Chrome-இல் இணைப்பைத் திறக்கவும்.
2. மேலே வலது மூலையில் உள்ள மூன்று புள்ளி ⋮ பொத்தானைத் தொடவும்.
3. **"Install app"** அல்லது **"Add to Home screen"** என்பதைத் தொடவும்.
4. முகப்புத் திரையில் கைப்பேசி ஜோதிடர் சின்னம் (icon) வரும். அதைத் தொட்டுத் திறக்கவும்.

**ஐபோன் (iPhone) — Safari உலாவி:**

1. **Safari**-யில் இணைப்பைத் திறக்கவும் (Chrome அல்ல, Safari தான்).
2. கீழே உள்ள **பகிர்வு (Share)** பொத்தானைத் தொடவும் (மேல் நோக்கிய அம்புடன் கூடிய சதுரம்).
3. கீழே நகர்த்தி **"Add to Home Screen"** என்பதைத் தொடவும் → **Add**.
4. முகப்புத் திரையில் வரும் சின்னத்தைத் தொட்டுத் திறக்கவும்.

**ஹுவாவே (Huawei):** Huawei Browser-இல் இணைப்பைத் திறந்து → மெனு ☰ → **"Add to home screen"**.

> இணைய இணைப்பு இன்னும் இல்லையா? படி (ஆ)-வில் உள்ள APK முறையைப் பயன்படுத்துங்கள். அதற்கு இணைப்பு தேவையில்லை.

## ஆ) ஆண்ட்ராய்டு செயலி (APK) — GitHub மூலம் உருவாக்கி நிறுவுதல்

APK என்பது ஆண்ட்ராய்டு செயலிக் கோப்பு. GitHub தானாகவே அதை உருவாக்கித் தரும். உங்கள் கணினியில் எதையும்
நிறுவ வேண்டியதில்லை.

### 1. செயலியை உருவாக்குதல்

1. கணினியிலோ கைப்பேசியிலோ உலாவியில் உங்கள் GitHub களஞ்சியத்தை (repository) திறக்கவும்:
   `https://github.com/sureshakthii/Suresha`
2. மேலே உள்ள **Actions** தாவலைத் தொடவும்.
3. இடப்பக்கப் பட்டியலில் **"Mobile apps"** என்பதைத் தேர்ந்தெடுக்கவும்.
4. வலப்பக்கம் **"Run workflow"** → மீண்டும் பச்சை **"Run workflow"** பொத்தானை அழுத்தவும்.
   (மாற்று வழி: `v1.0.0` போன்ற பதிப்புக் குறிச்சொல் (tag) சேர்த்தாலும் தானாகத் தொடங்கும்.)
5. சுமார் 10–15 நிமிடம் காத்திருக்கவும். பச்சை ✔ குறி வந்தால் வேலை முடிந்தது.

### 2. APK கோப்பைப் பதிவிறக்குதல்

1. முடிந்த அந்த ஓட்டத்தை (run) திறக்கவும்.
2. கீழே **Artifacts** பகுதியில் **`kaippesi-android-debug-apk`** என்பதைத் தொட்டுப் பதிவிறக்கவும்.
3. அது ஒரு ZIP கோப்பாக வரும். அதைத் திறந்தால் (unzip) **`app-debug.apk`** கிடைக்கும்.

### 3. கைப்பேசியில் நிறுவுதல்

1. `app-debug.apk` கோப்பைக் கைப்பேசிக்கு அனுப்பவும் — USB கம்பி, Google Drive, அல்லது WhatsApp-இல்
   உங்களுக்கே அனுப்பி (ஆவணமாக — "Document") பெறலாம்.
2. கைப்பேசியில் அந்தக் கோப்பைத் தொடவும்.
3. "இந்த மூலத்திலிருந்து நிறுவ அனுமதி இல்லை" என்று வந்தால் → **Settings** → **"Install unknown apps"
   (அறியாத செயலிகளை நிறுவுதல்)** → நீங்கள் பயன்படுத்தும் செயலிக்கு (Files / Chrome / WhatsApp) அனுமதி கொடுக்கவும்.
4. மீண்டும் **Install** → **Open**. அவ்வளவுதான்! 🎉

Play Protect எச்சரிக்கை வந்தால் **"Install anyway"** அழுத்தலாம். இது உங்கள் சொந்தச் செயலி; கடையில்
இன்னும் பதிவாகாததால் மட்டுமே இந்த எச்சரிக்கை.

**ஹுவாவே கைப்பேசிகள்:** இதே APK ஹுவாவே கைப்பேசியிலும் நிறுவும். Google சேவைகள் தேவையில்லை.

### 4. உறவினர்களுக்குச் சோதனைக்குக் கொடுத்தல் (1 நாள் சோதனை)

- இதே `app-debug.apk` கோப்பை WhatsApp / Google Drive மூலம் உறவினர்களுக்கு அனுப்புங்கள். மேலே உள்ள
  படி 3-ஐ அவர்களும் செய்தால் போதும்.
- இப்போதைய தனித்து இயங்கும் செயலியில் எல்லா ஜோதிடக் கணக்குகளும் இலவசமாக இயங்கும் — தனியாக "சோதனைக் காலம்"
  அமைக்கத் தேவையில்லை.
- சேவையகம் வந்த பிறகு (படி உ), 1 நாள் இலவச பிரீமியம் சோதனை தானாகக் கிடைக்க, சேவையக அமைப்பில்
  `TRIAL_HOURS=24` என வைக்கலாம். அன்பளிப்புக் குறியீடுகளையும் (gift codes) கொடுக்கலாம்.
- அவர்களின் கருத்துகளை ஒரு குறிப்பேட்டில் எழுதி வையுங்கள் — எது பிடித்தது, எது புரியவில்லை.

## இ) ஐபோன் (iPhone) — மூன்று வழிகள்

ஆப்பிள் விதிகளின்படி, கடையில் இல்லாத செயலியை ஐபோனில் நிறுவ **Mac கணினி + Xcode** தேவை. எனவே:

### வழி 1: Safari மூலம் முகப்புத் திரையில் சேர்த்தல் (மிக எளிது)

படி (அ)-வில் உள்ளபடி Safari → Share → **Add to Home Screen**. எந்தக் கட்டணமும் இல்லை. இணைய இணைப்பு
(web link) மட்டும் தேவை.

### வழி 2: TestFlight / நேரடி நிறுவல் (Mac + Apple ID தேவை)

- **இலவச Apple ID:** உங்கள் சொந்த ஐபோனில் மட்டும் நிறுவலாம்; **7 நாளுக்கு ஒருமுறை** மீண்டும் நிறுவ வேண்டும்.
- **Apple Developer Program (ஆண்டுக்கு US$99):** TestFlight மூலம் 10,000 பேர் வரை சோதிக்கலாம்;
  App Store-இலும் வெளியிடலாம்.

Mac-இல் செய்ய வேண்டியவை:

1. Mac App Store-இலிருந்து **Xcode** நிறுவவும். [nodejs.org](https://nodejs.org)-இலிருந்து Node.js 22 நிறுவவும்.
2. Terminal-ஐத் திறந்து, திட்டக் கோப்புறையில் (project folder) இவற்றை ஒவ்வொன்றாக இயக்கவும்:
   ```bash
   npm ci
   npm run mobile:ios
   npx cap open ios
   ```
3. Xcode திறக்கும். இடப்பக்கம் **App** → **Signing & Capabilities** → **Team** என்பதில் உங்கள் Apple ID-ஐத்
   தேர்ந்தெடுக்கவும் (முதல் முறை "Add an Account" மூலம் சேர்க்கவும்).
4. ஐபோனை USB கம்பியால் Mac-உடன் இணைத்து, மேலே சாதனமாக உங்கள் ஐபோனைத் தேர்ந்தெடுத்து ▶ **Run** அழுத்தவும்.
5. ஐபோனில் **Settings → General → VPN & Device Management** → உங்கள் Apple ID-ஐ "Trust" செய்யவும்.
   (புதிய iOS-இல் **Settings → Privacy & Security → Developer Mode** இயக்கவும் கேட்கலாம்.)
6. TestFlight-க்கு: Xcode-இல் **Product → Archive → Distribute App → App Store Connect → Upload**.
   பிறகு App Store Connect-இல் TestFlight தாவலில் சோதனையாளர்களைச் சேர்க்கவும்.

### வழி 3: டெவலப்பர் உதவி

Mac இல்லையென்றால், நம்பகமான ஒரு டெவலப்பரிடம் இந்தக் கோப்பையும் `docs/MOBILE.md`-ஐயும் காட்டுங்கள்.
அவர் தனது Mac-இல் 30 நிமிடத்தில் செய்துவிடுவார். உங்கள் Apple கணக்கை அவர் Team-இல் சேர்த்தால் போதும்.

## உ) பிறகு: சேவையகத்தை (server) இயக்குதல்

சேவையகம் வந்தால் உள்நுழைவு, குடும்ப ஜாதகங்களை எல்லாக் கைப்பேசியிலும் பெறுதல், கட்டணம், புரோகிதர் முன்பதிவு,
AI ஜோதிடர் விரிவான பதில், காலை நினைவூட்டல் எல்லாம் இயங்கும்.

1. `docs/DEPLOY.md` வழிகாட்டியைப் பின்பற்றி **Render** (எளிது) அல்லது Docker மூலம் சேவையகத்தை இயக்கவும்.
2. உலாவியில் `https://<உங்கள்-டொமைன்>/api/health` திறந்தால் `{"ok":true,...}` வர வேண்டும்.
3. GitHub → **Settings → Secrets and variables → Actions → Variables** → **New repository variable**:
   பெயர் `KJ_APP_URL`, மதிப்பு `https://<உங்கள்-டொமைன்>` (கடைசியில் `/` வேண்டாம்).
4. மீண்டும் **Actions → Mobile apps → Run workflow**. இனி வரும் செயலி உங்கள் சேவையகத்தைத் திறக்கும்.
   அதன் பிறகு இணையதளத்தில் செய்யும் மாற்றங்கள் கடை புதுப்பிப்பு இல்லாமலேயே செயலியில் தெரியும்.
